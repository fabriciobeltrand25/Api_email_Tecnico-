# 🛠️ Sistema de Soporte Técnico Cloud

Aplicación web para reporte de incidencias técnicas con envío automático de correos mediante EmailJS.

## 📋 Características

- ✅ Formulario completo de reporte de incidencias
- ✅ Validación de datos en tiempo real
- ✅ Envío automático de correos al administrador
- ✅ Confirmación al usuario
- ✅ Interfaz intuitiva y responsive
- ✅ Sin almacenamiento de datos (seguridad)
- ✅ Desplegable en Streamlit Cloud

## 🚀 Tecnologías

- Python 3.8+
- Streamlit
- EmailJS API
- Requests
- python-dotenv
